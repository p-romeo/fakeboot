# Fakeboot

**The social graph of fake shoe-repair storefronts** — an interactive investigation microsite by Paul Romeo.

Live at [https://fakeboot.paulromeo.net](https://fakeboot.paulromeo.net) (Cloudflare Worker).

## Deploy

```bash
npm ci
npx wrangler deploy
```

Worker name: `fakeboot`. Custom domain: `fakeboot.paulromeo.net`.
