How the factory works

1. Fake local shop sites
Look like real cobblers/tailors, claim real addresses and family histories.
2. Shared stack
Namecheap registrations, Cloudflare NS pairs, EasyEngine/WordPress, shared public handle viethoa24 (handle only — not a proven person).
3. Checkout hop
Cart/checkout preloads third-party payment hosts (PayPal Client IDs + cart proxies).
4. Platform pollution
Fake website fields appear on Google Maps listings for the real victim businesses.
